## 🚀 Featured Projects

### 🔹 DevConnect API

A backend platform that allows developers to register, showcase projects, and search for peers by skill.

**Tech Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Pydantic · JWT · bcrypt · Docker · Render

* Built **24 API endpoints** for developer registration, projects, and skill-based peer search.
* Designed a PostgreSQL database with **5 relational tables** using SQLAlchemy.
* Implemented secure authentication using **JWT access tokens** and **bcrypt password hashing**.
* Containerized the application with Docker and deployed it on Render.
* Added interactive Swagger API documentation.

🔗 [View Repository](https://github.com/Debjyoti777/DevConnect)

---

### 🔹 Hand Gesture Recognition System

A real-time computer vision system for recognizing hand gestures and enabling touchless computer interaction.

**Tech Stack:** Python · TensorFlow · OpenCV · MediaPipe · Flask · PyAutoGUI

* Trained a gesture recognition model using a custom dataset of **995 landmark samples across 7 gesture classes**.
* Used MediaPipe and OpenCV to detect hand landmarks and extract **42 coordinate features** per hand frame.
* Trained a TensorFlow neural network that achieved **100% test accuracy** on a separate 199-sample test dataset.
* Built a Flask dashboard with virtual mouse controls, media shortcuts, sign language mapping, and touchless air drawing.

🔗 [View Repository](https://github.com/Debjyoti777/hand-gesture)
